2.对话栏要有一个关闭键
3.把10这一个常量改成10-60s后消失
3.对话栏默认一直存在（设置里面可以手动改成10-60秒后消失）
---

## 落地记录（2026-10-20）

### 对应关系

| 需求 | 做法 |
|---|---|
| 1. 设置里要有关闭键 | 面板顶部新增 `.pet__settings-head`：左「设置」标题 + 右 `✕`（`#settingsCloseBtn`）。另加 **Esc 关闭**（弹层类界面的默认期待）。「⚙ 设置」回归单一职责：只负责打开，不再兼职关闭 |
| 2. 对话栏要有关闭键 | 气泡右上角加 `#bubbleCloseBtn`。**只藏气泡，输入行还在**；再发一句话 `addMessage()` 会把气泡拉回来，所以不需要额外的"重新打开"按钮 |
| 3. 10 秒常量改成 10~60 秒 | `config.ts` 里 `AUTO_HIDE_DELAY_MS = 10000` 删除，改为 `AUTO_HIDE_MIN_S / MAX_S / STEP_S / DEFAULT_S` + `clampAutoHideSeconds()`。设置里用 `<input type="range" min=10 max=60 step=5>`，拖动时数字实时更新 |
| 4. 默认一直存在 | `store.autoHide.enabled` 默认 **false**；UI 上 checkbox 默认不勾、滑块置灰。`ui.ts` 模块内的 `autoHideEnabled` 也由 `true` 改成 `false` |

### 改动文件

- `TS/config.ts`：常量组 + `clampAutoHideSeconds()`（localStorage 可被手改，所以夹在代码里而不是只靠控件限制）
- `TS/store.ts`：`AutoHideSetting` 类型、`loadAutoHide()`（读坏了退回默认，不崩）、`saveAutoHide()`
- `TS/ui.ts`：新增 `settingsCloseBtn / bubbleCloseBtn / autoHideRange / autoHideValue` 引用；`openSettings / closeSettings / toggleSettings / isSettingsOpen`；`showBubble / closeBubble`；`setAutoHideDelay()`；`autoHideEnabled` 默认 false
- `TS/settings.ts`：`initPanelOpenClose()`（✕ + Esc 两处都走 `ui.closeSettings()`）；`initMiscSection()` 重写为「灌值 → 绑定 → `applyAutoHide()`」；`applyAutoHide()` 把 store 一份真相同步给控件和定时器
- `TS/chat.ts`：绑定气泡收起键；`settingsPanel.classList.remove('hidden')` 改为 `ui.openSettings()`（不再直接摸 classList）
- `TS/main.ts`：招呼语也算一次新消息，跟着 `ui.scheduleAutoHide()`
- `index.html`：气泡加收起键、面板加顶栏、其他区改成「checkbox + range」
- `CSS/common.css`：`.pet__icon--close`（灰底小圆）、`.pet__icon--bubble-close`（气泡同色系、默认半透明、hover 变实）、`.pet__range`（含 disabled）
- `CSS/style.css`：`.pet__bubble { position: relative }`、`.pet__log { padding-top: 18px }`（给关闭键让出一条，消息不会钻到下面）、`.pet__settings-head`
